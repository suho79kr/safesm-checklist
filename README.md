# SafeSM — 개요

> 안전은 기록에서 시작됩니다.

SafeSM은 1인 AI 스튜디오 [세라윤](https://serayun.com)이 만드는 **택배 현장 일일 점검·안전교육 기록 도구**입니다.
이 저장소는 코드가 아니라, SafeSM이 어떤 문제를 어떤 구조로 풀려는지 설명하는 **공개 개요**입니다.

> ⚠️ SafeSM은 **파일럿(시제품)** 단계입니다. 아래 흐름은 시제품 범위이며, 현장 검증을 마쳤다는 뜻이 아닙니다.
> SafeSM은 기록을 돕는 도구일 뿐, 어떤 법적·규제 요건도 자동으로 충족해 주지 않습니다.

## 왜 만들었나

종이로 하는 일일 차량 점검은 건너뛰기 쉽고, 날짜를 거슬러 적기 쉽고, 검토하기 어렵습니다.
SafeSM은 점검을 **짧은 모바일 습관**으로 바꾸고, 그 습관 하나하나를 **누군가 실제로 검토할 수 있는 기록**으로 남기려는 시도입니다.
만드는 사람이 직접 택배 일을 하고 있어서, 현장에서 느낀 불편에서 출발했습니다.

## 흐름

```
기사가 점검표 열기 → 항목 + 문제 + 사진 → 제출(시각 기록) → 관리자 검토 → 월별 이력 / PDF
```

## 시제품 범위

| 기능 | 설명 |
|---|---|
| 일일 차량 점검 | 차량과 안전 장비 항목을 휴대폰으로 몇 분 안에 |
| 문제 + 사진 | 문제가 있으면 사진을 붙여 보고 |
| 정직한 시각 | **점검 대상 날짜**와 **실제 제출 시각**을 따로 기록 |
| 운행 상태 | 운행 / 미운행 / 휴무 구분 |
| 역할 | 기사 / 관리자 / 최고 관리자 |
| 교육과 이력 | 안전교육 기록, 월별 이력, PDF 문서 |

계획(아직 꺼짐): 여러 대리점 구조, 검토·보고 기능 다듬기.
